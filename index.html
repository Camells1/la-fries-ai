What this actually is: a from-scratch, hand-written character-level language model, small enough to run entirely on your device — no server, no account, no API cost. It learned its style and its own name from a small original corpus, so it can write a short essay or story and knows who it is. It does not know current events or facts about the world, and it cannot browse the web — at this size that would just mean confidently making things up.
